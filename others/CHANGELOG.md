# 更新日志（CHANGELOG）

本项目从 v1 到 v11 的完整迭代记录，按时间顺序排列。

## [v11.2] - 2026-10-25

### 修复（关键）
- **视口修复**：`width=1280` → `device-width`，激活全部移动端断点样式（此前手机上访问的只是"缩小的桌面版"，移动端 CSS 从未生效）

### 无障碍（新增维度）
- 导航链接 / 品牌区补 `role="button"` + `tabindex="0"`，支持键盘 Tab 聚焦与回车/空格触发
- 新增 focus-visible 金色焦点环；图标按钮（📷 发图 / 🎤 语音）补 aria-label

### 工程质量
- **JS 模块化拆分**：单文件 3400 行内联脚本解包并拆分为 `js/` 下 8 个功能模块（boot/book/chat/ai-core/sensory/tests/site-shell/nav-community），HTML 降至 0.07MB
- **CSS 分离**：1500 行内联样式提取为 `css/style.css`（约 91KB），结构 / 样式 / 行为彻底分层
- **目录规范化**：根目录收敛为 `css / html / images / others / index.html`（+ 运行必需的 js/videos/audio/manifest/sw）；`serverless/` 代理示例与 `.env.example` 移入 `others/`
- **密钥安全升级**：新增后端中转代理（Vercel Functions + Cloudflare Workers 双版本，SSE 流式直通）与 `.env.example` 模板；AI 设置面板新增「后端中转」服务商——真实 Key 只存服务端，前端零泄露

### 性能
- 15 张大图转 WebP（2805KB → 2047KB）并清理无引用旧 JPG，images 目录 6.7MB → 5MB

### 体验与传播
- 补齐 Open Graph / Twitter Card 分享元信息与 og:image 分享封面图
- **PWA**：新增 manifest.json + Service Worker（静态资源缓存优先、HTML 网络优先），可安装、断网可演示
- 新增全局错误兜底：未捕获异常 / Promise 拒绝 → 友好 toast（节流），杜绝演示白屏
- 新增 AI 接口域名 preconnect / dns-prefetch 预连接

### 文档
- 新增《演示视频分镜脚本.md》（6.5 分钟逐镜头拍摄/剪辑指引与提交清单）
- README 技术栈 / 目录结构同步 v11.2
- 参赛资料全面同步当前版本：技术文档 / 作品介绍更新至 v11.2（多服务商 AI、Function Calling、向量 RAG、PWA、无障碍等），网页版 HTML 与 PDF 重新导出（UTF-8 无乱码）

## [v11.0] - 2026-10-25

### 安全（重要）
- **移除源码中硬编码的 DeepSeek API Key**（大赛要求密钥不得出现在公开仓库；旧 Key 已作废，请在设置面板填入自己的 Key）
- 默认服务商切换为免费体验接口（无需 Key，联网即用）

### 性能
- 全站 base64 内嵌资源外置：26 张图片 → `images/`、3 段视频 → `videos/`、背景音乐 → `audio/bgm.mp3`，HTML 体积从 40MB 降至 0.45MB
- 所有 `<img>` 添加 `loading="lazy"` 懒加载

### AI 能力升级
- **SSE 流式输出**：大模型回复逐字流式渲染（stream: true），替换原一次性返回
- **Function Calling**：新增 OpenAI tools 协议定义（navigate_view / search_knowledge / sensory_experience），AI 自主决策调用工具，执行后二次请求生成最终回复；回复中以可点击按钮形式给出板块入口（不自动跳转页面）
- **RAG 升级**：知识库检索增加字符二元组向量 + 余弦相似度，与关键词计分混合排序；思考态展示"已检索到 N 条站内科普资料"
- **多模态·图片理解**：对话框新增 📷 发送图片（本地 canvas 压缩至 640px），智谱/通义自动切换视觉模型看图解读
- **多模态·TTS 朗读**：每条 AI 回复可一键朗读（Web Speech API，用户主动触发）
- **AI 安全兜底**：检测自伤/轻生倾向时，优先展示心理援助热线卡片（12356 / 010-82951332 / 120），不经大模型
- **降级明示**：接口失败切换本地应答时，回复头部明确提示"已切换本地知识库应答"

### 界面与交互
- 顶部导航从 13 个平铺链接收敛为 5 个下拉分组（认识他们/看见他们/支持他们/参与进来/更多），移动端改为汉堡菜单 + 手风琴展开
- 首页数据看板折叠为 `<details>`，首屏更聚焦
- 首页三张快捷卡片图标差异化（🔍 / 🤍 / 💛）
- 快速小问卷新增计分结果页：了解指数 + 继续深入了解入口按钮
- 对话气泡文字支持换行排版（white-space: pre-line）
