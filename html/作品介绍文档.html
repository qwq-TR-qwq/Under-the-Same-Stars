一、项目详情及使用方式

1.1 项目背景

自闭症（自闭症谱系障碍）是一种神经发育差异，国内患者数量超千万。社会大众对自闭症存在大量误解：以为是性格内向、是家庭教育不当、是"天才病"。同时，自闭症儿童家长、特教老师、医护人员等长期处于高压状态，缺乏情绪出口。

本项目以"理解、包容、希望"为基调，构建一个公益科普 Web 应用，面向普通市民、学生、志愿者、企业、自闭症儿童家长等多类人群，通过科普知识、真实故事、数据可视化、感官体验和 AI 心理陪伴，消除社会对自闭症的误解。

1.2 使用方式

本项目为纯静态免构建网站，无需安装、无需构建：

  1. 双击打开 index.html（保持与 css/、js/、images/、videos/、audio/ 目录同级）
  2. 浏览器自动加载，即可浏览全部内容；在线演示地址：https://qwq-tr-qwq.github.io/Under-the-Same-Stars/ （GitHub Pages 托管，随仓库自动更新）
  3. 点击导航栏切换板块：首页、科普、故事、数据、体验、对话、家庭、公益、关于
  4. 点击"星语对话"进入 AI 心理陪伴，输入文字即可获得共情回答（支持流式输出、图片理解、语音输入与朗读）
  5. 点击"进入星星的视角"观看自闭症儿童视角的公益视频
  6. 家长用户可点击对话页"家长专区"入口：60 秒自评导航、29 个高频难题循证应答、就医准备清单一键生成可打印 A4 单页
  7. 顶栏或右下角「⚙ 设置」面板：统一管理主题外观（深色·星夜 / 浅色·日光）、网页动态效果（快捷键 Shift+L）、字号大小、背景音乐，全部自动记忆
  8. 支持 PC 端和手机端自适应浏览；支持安装为 PWA 应用，断网可离线演示

二、项目亮点

2.1 双链路 AI 心理陪伴（核心亮点）

  • 多服务商在线模式：支持后端中转 / DeepSeek / 智谱 GLM / 通义千问 / 免费体验接口（OpenAI 兼容协议），SSE 流式输出、打字机效果
  • 真 Function Calling：通过 OpenAI tools 协议定义 3 个站内工具（板块跳转 / 知识库检索 / 感官体验），大模型自主决策调用后二次请求生成回复
  • RAG 知识库：站内科普条目字符二元组向量化 + 余弦相似度与关键词计分混合排序，Top3 注入 System Prompt
  • 本地兜底全覆盖：内置 145 组话题键的共情应答库，覆盖 12 类人群 60+ 细分场景与 23 类高频现实困境（经济压力、霸凌、丧亲、容貌焦虑、家暴等），比赛现场断网也能演示
  • 21 个科普话题专门回答：自闭症、ADHD、抑郁、焦虑、失眠、压力等话题精确匹配长回答，问什么答什么
  • 多模态交互：图片上传看图理解（视觉模型自动切换）、语音输入、TTS 朗读回复（6 种音色预设，优先神经语音、按句分段留白；朗读逐句高亮 + 进度条，点击任意一句从该句跳读；自动跳过括号内注释）
  • 家长专区 · 家属专项对话：面向自闭症患者家属，内置 6 大类 29 个高频难题的循证应答 + 四层关键词体系 957 词精准召回，自由提问也能命中；回答坚持「先共情、给可操作步骤、讲清求助边界」，不做诊断、不推荐机构、不承诺疗效
  • 60 秒自评导航：5 道选择题帮家长定位最急的问题（行为/沟通/入园/情绪），自动跳到对应分类——导航而非诊断
  • 情绪安全阀：检测到孩子自伤/走失/极端情绪信号时，先置顶弹出 120/12356/110 求助卡片（可点击拨号），再给出专项建议——危机场景下响应顺序就是专业性
  • 就医准备清单生成器：勾选 25 项循证观察项（可注频率）+ 填写最担心的事与时间线，一键生成结构化 A4 打印单带去儿保科，勾选记录本机持久化可分天补充
  • AI 链路健康诊断：设置面板一键诊断「本地知识库 → 免费接口 → 中转 → 自填 Key」四级链路，明确显示当前降级到第几层，把兜底设计显性化
  • 未命中问题日志：本地没答上的问题自动记录，支持一键导出 CSV——以真实用户提问数据驱动知识库迭代方向
  • AI 安全兜底：自伤 / 轻生等危机关键词优先触发 12356 热线卡片；接口失败自动降级本地应答并明示
  • 共情式回答：每条回答先共情再展开，结尾引导用户继续说，不公式化、不预设身份年龄
  • 密钥安全：源码零密钥，个人使用密钥存本机 localStorage，正式部署可走 serverless 后端中转，真实 Key 不落前端

2.2 感官体验模拟

嵌入 B 站公益视频，让普通人直观感受自闭症儿童眼中的世界，用体验替代说教。视频带封面、点击暂停/继续，离开页面自动停止，下方黄色超链接可跳转 B 站原视频观看。

2.3 数据可视化

三张 Canvas 自绘图表（折线图 + 两个饼图），零依赖、离线可用，全部支持 hover 双向联动高亮，折线图 2016 年双数据分色标注，直观展示国内自闭症患病率趋势、国际对比、年龄分布。

2.4 星空治愈视觉

二次元星空动画背景 + 温暖配色，把沉重话题做温暖，不卖惨、不渲染悲情。

2.5 隐私保护

所有故事用插画代替真人照片，不使用患儿真实人脸。

2.6 演示稳定性与工程质量

针对比赛现场环境做了大量稳定化处理：全站视频不自动播放、离开页面即暂停；背景音乐全页通用可一键开关；TTS 朗读为用户主动触发、离开对话页即停；全局错误兜底 toast 杜绝白屏；PWA 离线缓存让断网也能完整演示。偏好设置中心统一管理主题外观 / 网页动态效果 / 字号 / 背景音乐：浅色模式（日光纸白 + 深色墨字，高对比）与网页动态效果（关动效/音乐/视差/弹幕，保留换页叙事动画）为感官敏感人群与明亮环境提供舒适版本。数据看板升级为可追溯数据层（唯一数据源 stats.json：20 个数据点 + 10 条权威来源，带口径与推算依据，线上改 JSON 即时生效、离线自动兜底）。工程上 HTML / CSS / JS 分层（HTML 0.11MB + css/style.css + others/js/ 16 个功能模块），免构建、双击即用，并已托管 GitHub Pages 在线演示。

四、关键技术

4.1 前端技术

  • 原生 HTML5 + CSS3 + JavaScript（ES6+）：免构建零依赖；HTML / CSS（css/style.css）/ JS（others/js/ 16 个功能模块）分层，双击即用
  • 原生 Canvas 2D 图表：数据可视化，折线图 + 饼图，支持 hover 交互，零依赖；随主题切换自动重绘（浅色模式浅底深字）
  • 响应式设计：device-width 视口 + CSS 媒体查询断点，移动端汉堡导航，键盘可达 + focus-visible 焦点环
  • 偏好设置中心：主题外观 / 网页动态效果 / 字号大小 / 背景音乐四项统一入口，状态仅存 localStorage、刷新自动恢复
  • 浅色模式：<html class="theme-light"> 单一状态真相，渲染前预应用防闪烁；日光纸白配色 + 深色墨字（正文对比度 ≥ 4.5:1），约 400 行覆盖规则逐组件适配，书页背景换晨光渐变
  • 网页动态效果（原低刺激模式）：<html class="motion-off"> 单一状态真相，渲染前预应用防首屏闪烁；减少动效时 CSS 将动画压至瞬时（保留最终帧防残缺态），JS 监听自定义事件实现「减少即静音、恢复继续」；换页叙事动画通过高优先级规则豁免；旧版低刺激存档自动迁移
  • 浮层无障碍统一接管：零侵入 MutationObserver 方案，7 个浮层自动获得焦点移入、Tab 循环锁定、ESC 关闭、焦点归还
  • 资源外置 + 懒加载 + WebP：图片/视频/音频独立文件，loading="lazy" + 固有宽高防布局抖动，HTML 仅 0.11MB
  • 数据看板数据层：唯一数据源 others/data/stats.json（20 个数据点 + 10 条权威来源），每个点带类型（发布值/估算/差额推算）与来源引用；同步脚本校验并生成注入文件；线上自动 fetch JSON 即时生效、离线 <script> 注入兜底
  • PWA：manifest + Service Worker 离线缓存（v18），断网可演示

4.2 AI 技术

  • 多服务商大模型集成：后端中转 / DeepSeek / 智谱 GLM / 通义千问 / 免费体验接口（OpenAI 兼容协议，可切换）
  • SSE 流式输出：逐 token 打字机渲染
  • 真 Function Calling：OpenAI tools 协议 3 个站内工具，流式解析 tool_calls 并二次请求
  • RAG 混合检索：字符二元组向量化 + 余弦相似度 + 关键词计分混合排序，Top3 注入 Prompt，检索可视化
  • 多模态：语音输入（Web Speech API）+ TTS 朗读（6 种音色预设、优先神经语音、按句分段留白、逐句高亮 + 点句跳读、自动跳过括号注释与表情）+ 图片上传看图理解（glm-4v-flash / qwen-vl-plus 自动切换）
  • RAG 本地知识库：145 组话题键人工撰写共情应答 + 21 个科普话题精确回答，计分制关键词匹配；家长专区另设四层关键词体系 957 词（高置信 138 / 核心 448 / 辅助 304 / 排除 67）
  • 四层降级：在线 API → 17 话题 → 本地知识库 → 通用兜底；链路诊断可视化当前层级
  • AI 安全：情绪安全阀统一入口（家长语境 / 本人危机分流，60 秒节流）、危机干预关键词兜底（120/12356/110 卡片优先响应）、降级明示
  • 数据驱动迭代：未命中问题日志（去重、上限 200 条）一键导出 CSV，按真实提问反推知识库补充方向
  • System Prompt 工程：先共情再展开、不机械分点、不预设身份、结尾引导

4.3 交互技术

  • 打字机效果：AI 回答逐字显示
  • 思考态："星语正在思考..."状态提示 + 检索命中可视化
  • 语音进度交互：朗读时当前句高亮、气泡内进度条跟随，点击任意句从该句跳读
  • 图表联动：hover 图形和图例双向高亮
  • 视频控制：点击暂停/继续，离开页面自动暂停并回到开头
