# 环境配置与运行说明

## 一、运行环境

| 项    | 要求                          |
| ---- | --------------------------- |
| 操作系统 | Windows / macOS / Linux     |
| 浏览器  | Chrome / Edge / Firefox 最新版 |
| 网络   | 在线对话需联网；离线时本地兜底仍可用          |
| 依赖   | 无（纯静态页面，无需 npm install）  |

## 二、快速运行

1. 解压或下载项目（保持 `index.html` 与 `css/`、`images/`、`others/` 目录的相对位置，JS 与媒体资源都在 `others/` 内）

2. 双击 `index.html`

3. 浏览器自动打开即可使用

> 推荐通过本地静态服务器运行（如 VS Code Live Server），直接双击也可正常运行。

## 三、API Key 配置

### 安全说明（重要）

**源码中不包含任何 API Key。**根据大赛"API 密钥不得出现在公开仓库"的要求，所有密钥一律由使用者自行配置，仅保存在本机浏览器 localStorage，不会进入代码仓库。

### 默认配置

默认使用「免费体验接口」（pollinations，无需 Key），联网即可体验真实大模型对话。

### 自定义配置

1. 打开对话页，点击右上角 "⚙ 设置" 按钮

2. 选择服务商并填写：

* API Key：你的 Key（DeepSeek / 智谱 GLM / 通义千问 / 自定义 OpenAI 兼容接口）
* Model：随服务商自动填充，可修改（「自定义」需自行填写，模型名含 vl / vision / 4o 即按视觉模型处理）
* Endpoint：内置服务商固定用官方地址（防止旧地址残留导致 404），仅「自定义」需自行填写完整地址，须写到 `/chat/completions` 结尾

3. 配置自动保存在浏览器 localStorage（key: `star_ai_cfg_v1`）

4. 点「保存设置」，再点「链路诊断」——诊断会先测文本通道、再用内置测试图真发一次视觉请求，分别报「文本 ✓ / 看图 ✓」；失败时显示服务端原始报错（HTTP 状态 + JSON）

### 图片理解（多模态）

点对话框 📷 按钮选图即可发送，图片在浏览器内压缩后随消息发出，由所选服务商的视觉模型解读。可用通道：

| 通道 | 看图模型 | 说明 |
|---|---|---|
| 通义千问 | `qwen3-vl-plus`（自动） | 阿里云百炼需有可用额度 |
| 智谱 GLM | `glm-4v-flash`（自动） | 浏览器直连受跨域限制，需代理 |
| 自定义 | 自行填写，如硅基流动 `Qwen/Qwen3-VL-8B-Instruct` | 注册送额度、浏览器可直连，无额度时推荐 |
| DeepSeek / 免费接口 / 后端中转 | 不支持 | 发图会被当场拦截并提示切换 |

自定义通道接硅基流动的填法：服务商选「自定义」，接口地址 `https://api.siliconflow.cn/v1/chat/completions`，模型 `Qwen/Qwen3-VL-8B-Instruct`（纯聊天可换 `Qwen/Qwen3-8B`），Key 用 siliconflow.cn 创建的 `sk-`。平台模型名会更新，以「模型广场」里的完整 ID 为准。

## 五、部署上线

### GitHub Pages

1. 在 GitHub 新建公开仓库（如 `starry-night`）

2. 上传项目全部文件（`index.html` + `css/` + `images/` + `others/`）

3. 仓库 Settings → Pages → Source 选 `main` 分支

4. 访问 `https://<用户名>.github.io/<仓库名>/`

> 注意：上传前确认 `index.html.bak` 等备份文件已移出项目目录。

### 正式部署建议

若公开部署并希望使用自己的付费 Key，建议在服务端加一层轻量代理（如 Vercel Serverless Function）中转大模型请求：前端只调用代理地址，Key 仅存于服务端环境变量，避免泄露与前端 CORS 限制。

## 六、常见问题

**Q: 打开后对话没反应？**

A: 检查网络。接口不可用时会自动切换本地知识库应答，并在回复头部明确提示"已切换本地知识库应答"。

**Q: AI 调用工具有什么前提？**

A: Function Calling 需要配置 DeepSeek / 智谱 / 通义任一服务商的 Key（免费体验接口不支持 tools 协议，会走本地关键词意图识别降级，效果一致）。

**Q: 视频不播放？**

A: 保持 `others/videos/` 目录相对位置不变（勿单独移动视频文件）。换 Chrome / Edge 浏览器，手机端直接点击视频中央播放。

**Q: 图片看图理解不可用？**

A: 先点「链路诊断」看是「文本通道」还是「看图通道」失败：401 = Key 无效或不属于该平台；403 = 无调用权限（免费额度过期 / 未开通按量付费）；404 = 模型名已下线（如 `qwen-vl-plus` → `qwen3-vl-plus`）；429 = 配额用尽或限流。DeepSeek 与免费体验接口不支持视觉，请换通义千问或自定义通道（如硅基流动）。

**Q: 图表不显示？**

A: 图表为原生 Canvas 绘制，不依赖网络。首页数据看板默认折叠，点击「自闭症数据看板」展开即可。
