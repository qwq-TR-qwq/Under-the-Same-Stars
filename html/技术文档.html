1. 项目概述

1.1 背景

自闭症（自闭症谱系障碍）是一种神经发育差异，国内患者数量超千万。社会大众对自闭症存在大量误解：以为是性格内向、是家庭教育不当、是"天才病"。同时，自闭症儿童家长、特教老师、医护人员等长期处于高压状态，缺乏情绪出口。

1.2 目标

本项目以"理解、包容、希望"为基调，构建一个公益科普 Web 应用：

  • 科普消除误解：用通俗语言和互动体验，让普通大众真正理解自闭症
  • 看见患儿与家庭：通过故事和数据，让社会看见这群人和他们的家庭
  • 心理陪伴：用 AI 对话提供共情支持，缓解家长、老师、患者的情绪压力
  • 呼吁社会包容：给出普通人能做的小事，降低参与门槛

1.3 目标用户

人群需求
普通社会人士了解自闭症，知道如何正确对待
自闭症儿童家长心理疏导、资源指引、互助渠道
特教老师 / 医护情绪出口、职业压力缓解
自闭症青少年被理解、被接纳
大学生 / 职场人通用心理陪伴
企业 / 志愿者参与公益的入口

2. 需求分析

2.1 功能需求

  • 科普知识板块（什么是自闭症、误区、如何相处）
  • 真实故事板块（孩子视角、家长故事、老师视角）
  • 数据可视化（患病率趋势、国际对比、年龄分布）
  • 感官体验模拟（自闭症儿童视角体验视频）
  • AI 心理对话（在线 + 本地兜底）
  • 家庭支持站（资源指引、电子证书）
  • 公益参与（官方网站跳转、志愿登记）
  • 无障碍适配（大字模式、量表大字体）

2.2 非功能需求

  • 免构建模块化交付：纯静态文件，双击即可运行；HTML / CSS / JS 按职责分离
  • 离线可用：本地知识库兜底，断网时仍能对话（PWA 文件归档于 others/，离线缓存视托管环境生效）
  • 响应式：PC / 移动端均可用（device-width 视口 + 完整移动端断点）
  • 无障碍：键盘可达导航、focus-visible 焦点环、图标按钮 aria-label、大字模式
  • 隐私保护：不使用患儿真实照片
  • 基调正向：不卖惨、不渲染悲情
  • 密钥安全：源码零密钥；线上演示默认走 Cloudflare Worker 服务端代理（Key 只存在服务端环境变量），个人使用 Key 仅存本机浏览器
  • 演示稳定：不依赖现场网络（本地兜底 + 离线缓存双保险）

4.2.2 计分制匹配算法


function replyFor(text) {
  var tl = text.toLowerCase();
  // 1. 先做 17 话题精确匹配
  for(var key in TOPIC_REPLIES){
    if(text === key){ return TOPIC_REPLIES[key]; }
  }
  // 2. 测评结果特殊处理（MBTI / 量表得分）
  if(/测评结果|帮我分析|分析一下/.test(tl)){
    // ... 返回对应结果解读
  }
  // 3. 计分制匹配 REPLY_BANK
  var bestBank = null, bestScore = 0;
  for (var i = 0; i < REPLY_BANK.length; i++) {
    var bank = REPLY_BANK[i];
    var score = 0;
    for (var k = 0; k < bank.keys.length; k++) {
      if (tl.indexOf(bank.keys[k].toLowerCase()) >= 0) score++;
    }
    if (score > bestScore) { bestScore = score; bestBank = bank; }
  }
  if (bestBank) return pickOne(bestBank.replies);
  // 4. 兜底
  return pickOne(FALLBACKS);
}

设计要点：

  • 多关键词匹配：不依赖唯一关键词，统计命中关键词总数，选命中最多的条目，避免"用户说 A 却匹配到 B"
  • 家长专区四层词表：家属专项问答用 hi（高置信，单独出现即可作答）/ k（核心，需语境或词群）/ kw（辅助，只加分）/ x（排除，纠正易混主题）四层关键词，共 957 个。匹配前统一归一化——去标点、转小写、剔除口语虚词（"每天晚上都睡不着" 与 "每天晚上睡不着" 视为同一句），关键词不必为每种语序重复列一遍；计分时 hi 8 分起、核心词按长度 3-6 分、辅助词 1 分，阈值按有无家属语境在 3 / 5 分之间浮动。这样"娃两岁还不开口""一剪指甲就哭"能命中，"今天好累""考试前很焦虑"仍保持原样
  • 易混主题隔离：排除词专门隔开三组容易串味的问题——攻击他人 vs 自伤（"打我""打人" 不命中撞头答案）、生理不适 vs 照护倦怠（"感冒""胸闷" 不命中撑不住答案）、动作发育 vs 语言发育（"不会走路""不会穿鞋" 不命中不会说话答案）；排除词只在题目没有高置信词命中时生效，保证"他打我，还打自己头"这类复合句仍能拿到自伤答案
  • 身份判断：回答内容根据问题场景判断用户身份，未确定身份时不使用"二十多岁""学习压力"等预设词
  • 精确话题优先：科普站发起的话题直接精确命中，保证回答与问题完全对应
  • 测评结果解读：用户分享 MBTI 或量表得分时给出温和解读，不贴标签
  • 每条回答末尾随机追加引导语（"愿意多说说吗""现在感觉怎么样"等），避免对话一句话结束

4.3 System Prompt 设计


你是"星语"，一个温暖、共情的心理陪伴助手。
要求：
1. 先共情，再展开
2. 不要机械分点，像朋友聊天，回答要有足够篇幅
3. 针对用户说的具体事情回答，不要泛泛而谈
4. 不要预设用户身份、年龄（不知道对方是谁时不要说"二十多岁"这类词）
5. 信息不够时反问细节
6. 结尾引导用户继续说
7. 不做医疗诊断，严重问题建议就医或拨打 12356

4.4 流式输出与思考态

  • 调用 API 时显示"星语正在思考..."
  • 收到响应后逐字打字机渲染
  • 错误时友好提示，不白屏

4.5 对话稳定性设计

  • 取消自动跳转：早期版本在对话命中"政策/志愿者/压力大/画展/家庭"等关键词后会自动跳转到对应站内板块，造成"对话时突然跳转页面"。正式版移除全部自动跳转逻辑，AI 只在对话页内回答，页面保持稳定
  • 输入框自动聚焦恢复：进入对话页与 AI 回答完自动聚焦，便于连续输入

4.6 AI 安全与可控性

  • System Prompt 限制：不诊断、不开药、不鼓励自残
  • 严重心理问题自动提示就医与 12356 热线
  • 本地兜底回答均经过人工撰写，安全可控

8. 性能与安全

8.1 性能优化

  • 资源全部外置：图片 / 视频 / 背景音乐从 base64 内嵌外置为独立文件，HTML 从 40MB 降至 0.11MB
  • CSS / JS 分离：样式提取为 css/style.css，脚本拆分为 others/js/ 下 17 个模块，浏览器可并行下载与缓存
  • 图片懒加载：全部 <img> 添加 loading="lazy" decoding="async"，首屏只加载首屏资源
  • 图片 WebP 化：15 张大图转 WebP（2805KB → 2047KB）；书首页 hero 两张带透明通道 PNG 转 WebP（2.0MB → 205KB），images 目录 6.7MB → 2.6MB
  • 重复资源去重：校验 md5 后删除重复视频文件，节省约 10MB
  • 预连接：AI 接口域名 preconnect / dns-prefetch，降低首字延迟
  • 图表按需渲染：Canvas 图表在页面初始化时绘制，数据看板折叠为 <details> 不占首屏
  • 流式渲染：SSE 逐 token 更新 DOM，替代一次性大段插入，避免长回复卡顿
  • 打字机节流：避免高频 DOM 操作卡顿

8.2 安全性

  • 源码零密钥：API Key 不入库；个人使用通过设置面板配置（localStorage），正式部署使用 others/serverless/ 后端中转代理（Vercel Functions / Cloudflare Workers 示例 + .env.example 模板），真实 Key 只存服务端
  • 本地兜底回答人工撰写，无安全风险
  • 严重心理问题自动提示就医与 12356 热线（危机干预关键词优先于大模型响应）
  • 不收集用户隐私数据（对话仅在浏览器内存）
  • 公益链接使用 target="_blank" rel="noopener"，防钓鱼反向攻击
  • 全局错误兜底：未捕获异常只展示友好提示，不泄露技术细节
