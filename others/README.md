# 星夜入眠 · 关爱自闭症儿童公益科普网站

> 一个面向全社会的自闭症公益科普与心理陪伴 Web 应用，星空治愈风格，AI 星语对话 + RAG 知识库 + 感官体验模拟。

---

## 一、项目简介

**星夜入眠**是一个以"理解、包容、希望"为基调的自闭症公益科普网站。面向普通市民、学生、志愿者、企业、自闭症儿童家长等多类人群，通过科普知识、真实故事、数据可视化、感官体验模拟和 AI 心理陪伴，消除社会对自闭症的误解，呼吁社会包容。

网站采用二次元星空治愈风格，不渲染悲情、不卖惨，用温暖的视觉和共情的对话，让"星星的孩子"被看见。

## 三、核心功能

### 1. 科普认知板块

- 认识自闭症翻页动画：什么是自闭症、典型表现、常见误区、如何相处
- 动画末尾内嵌科普公益视频，点击可暂停/继续
- 科普小画廊（孩子绘画作品）

### 2. 看见他们：真实故事

- 孩子视角、家长故事、干预老师视角、成长案例
- 配二次元风格插图，保护隐私

### 3. 数据看板

- 数据层驱动：唯一数据源为 `others/data/stats.json`（20 个数据点 + 10 条权威来源，含机构/年份/口径/链接），由 `others/tools/sync-stats.js` 校验并生成 `others/js/data/stats.js` 注入页面
- 可定期更新：修改 `others/data/stats.json` → 运行 `node others/tools/sync-stats.js`；线上（GitHub Pages）还会自动 fetch 一次 JSON，只改 JSON 即时生效
- 离线不崩：双击打开（file://）时数据由 `<script>` 注入，无网络请求；数据文件缺失时自动回退内置兜底数据
- 2013–2025 年国内自闭症患者人数与儿童患病率图（人数首末为发布值、中间为估算；患病率三个口径点并列呈现、不连线、不可直接比较）
- 各国患者数量对比饼图（含全球约 6700 万 WHO 对照，「其他国家」为差额推算）
- 各年龄段构成饼图（按 14 岁以下约 500 万拆分示意）
- 全部支持 hover 交互高亮，悬停提示直接显示数值口径与来源；下方来源清单可逐条展开查看原文链接

### 4. 感官体验模拟

- 体验视频：嵌入 B 站公益视频（自闭症儿童视角），让普通人亲身体会"他们眼中的世界"
- 体验视频带封面，点击视频可暂停/继续，离开页面自动停止
- 两个视频下方给出提示："点击黄色字体跳转哔哩哔哩网页观看"（跳转 B 站原视频）

### 5. 星语对话（AI 心理陪伴）

- **多服务商大模型接入**：DeepSeek / 智谱 GLM / 通义千问 / 免费体验接口（默认，无需 Key 联网即用），OpenAI 兼容协议，设置面板一键切换
- **SSE 流式输出**：回复逐字流式渲染，思考态可视化；接口失败自动降级本地应答并明确提示
- **Function Calling 工具调用**：AI 自主决策调用站内工具——`navigate_view`（板块跳转按钮）、`search_knowledge`（知识库检索）、`sensory_experience`（感官体验模拟）；免费接口走本地关键词意图识别降级
- **多模态**：📷 发送图片由视觉模型解读（智谱 glm-4v-flash / 通义 qwen3-vl-plus 自动切换）；🔊 一键 TTS 朗读回复（默认温柔女声，另有温润 / 低沉男声；优先选用系统神经语音并按句分段留白，尽量贴近真人，朗读自动跳过括号注释；离开对话页自动停止）
- **RAG 静默检索**：命中结果只作为回答依据，不在气泡中显示检索提示，保持对话纯净
- **家长专区（家属专项对话）**：对话页内置「家长专区」入口，收录 6 大类 29 个自闭症家庭高频难题——刚确诊的情绪冲击与自责、情绪崩溃与自伤走失、不说话与听不懂、挑食睡眠如厕、上学与康复机构、家长自己的心理状态——每题都是审核过的循证内容：先接住情绪、再给今天回家就能做的 2-3 条、再讲清何时必须找专业帮助；家长自由提问也能按关键词命中专项答案；接 AI 后同样优先用审核过的答案应答，避免模型在医疗建议上自由发挥
- **RAG 本地知识库兜底**：内置 145 组话题键针对不同身份（特教老师、医护、单亲家长、退休老人、中小学教师、应届生、焦虑抑郁、亲密关系、留守儿童、普通社会人士、自闭症青少年、自闭症儿童家人、压力大学生、职场人等）的共情回答
- **17 个科普话题专门回答**：自闭症、ADHD、抽动障碍、抑郁、焦虑、双相、惊恐发作、失眠、压力、考试焦虑、社交、感情、失恋、安慰朋友、拖延、手机成瘾、亲子沟通，每个话题一段有共情、有建议、带引导的长回答
- **AI 安全兜底**：检测自伤/轻生倾向时，优先展示心理援助热线卡片（12356 等），不经过大模型
- **引导追问**：每条回答末尾引导用户继续说下去，避免一句话结束
- 对话全程**不自动跳转站内板块**，以可点击按钮形式给出入口，页面稳定

### 6. 家庭支持站

- 家长心理疏导、早期干预知识
- 资源指引（评估诊断、康复机构、残联政策）
- 电子公益证书生成

### 7. 政策与救助（省市二级 + 搜索记忆）

- 地区选择精确到市：31 个省级行政区 + 333 个地级行政区二级联动，直辖市下级自动切换为「全市」
- 排序：直辖市单独成组排在第一组，其余省份按拼音首字母 A–Z 分组；快捷芯片第一排固定 4 个直辖市
- 搜索：输入省名 / 市名实时建议，支持键盘上下键与回车；最近 5 条搜索记录（去重置顶、可一键清除）
- 官方入口：市政府门户 / 省残联 / 省政府门户 / 12345，链接文字为金黄色；市级门户逐条核验，未收录城市给出明确提示而非猜测链接
- 参考办理路径：评估与办证 → 备材料 → 提交申请与年度随访
- 选择结果写入 localStorage，下次访问自动恢复

### 8. 公益参与

- 普通人能做什么、志愿者招募说明
- 企业/商家合作方式、公益活动预告
- 官方网站入口：中国精协官网、中国残疾人福利基金会（新标签页打开，返回不丢失页面位置）

### 9. 偏好设置（无障碍与网页动态效果）

- **偏好设置中心**：顶栏/右下角「⚙ 设置」面板统一管理四项个性化调整——主题外观（深色·星夜 / 浅色·日光）、网页动态效果（开启全部动效 / 减少动效，快捷键 Shift+L）、字号大小（标准 / 大字）、背景音乐；全部设置仅保存在本机、刷新自动恢复
- **网页动态效果（原低刺激模式）**：减少动效时暂停背景音乐、鼠标视差、悬停音效与弹幕滚动，动画压至瞬时（保留换页叙事动画）——为自闭症谱系与感官敏感人群提供"安静的版本"
- **浅色模式**：日光纸白配色 + 深色墨字，书页换晨光渐变，图表随主题重绘；正文对比度 ≥ 4.5:1，白天与明亮环境更醒目
- **浮层焦点管理**：所有弹窗打开时焦点自动移入、Tab 循环锁定、ESC 关闭、焦点归还，读屏与键盘用户不会迷失
- **就医准备清单**：家长专区内置，勾选观察项（可注频率）+ 最担心的事 + 时间线，一键生成结构化 A4 打印单带去儿保科
- **情绪安全阀**：对话出现自伤/走失/极端情绪信号时，先置顶 120/12356/110 求助卡片（可点击拨号）再给建议
- **60 秒自评导航**：5 道题帮家长定位最急的问题，自动跳到对应分类（导航而非诊断）
- 大字模式（真实字体放大，不破坏排版）
- 心理量表题目大字体显示
- 背景音乐全局总开关（一键开/关）

## 四、AI 技术亮点

### 4.1 RAG 本地知识库

针对比赛现场可能断网、API 不可用的情况，构建了 145 组话题键的本地兜底回答，覆盖 12 类人群、60+ 细分场景。采用**计分制关键词匹配**：

```
用户输入 → 小写化 → 遍历 REPLY_BANK → 统计每个条目命中的关键词数 → 选命中最多的条目 → 返回
```

命中数 ≥ 2 的条目直接胜出；命中数 = 1 时接受较长关键词（≥3 字），避免单字误匹配。同时内置 17 个科普话题（autism/adhd/tourette/depression/anxiety/bipolar/panic/sleep/stress/exam/social/emotion/comfort/heartbreak/procrastinate/phoneaddict/parent）的**精确匹配长回答**，不走关键词计分，直接命中。

### 4.2 一周陪伴计划（三步规划工作流）

- 入口：对话页「一周陪伴计划」条 → `others/js/16-plan.js`
- 流程：描述困境 → AI 输出"还需确认什么"并追问 2–3 题 → 生成计划卡（今天一件事 / 本周目标 / 三个避坑 / 何时就医 / 排序依据）
- 闭环：逐日打卡（7 格），打卡满 2 天可"按执行情况调整"——第二轮 prompt 带完成率，要求"做到的保留、做不到的降难度"
- 兜底：本地规则库 8 类场景预设（公共场所崩溃 / 睡眠 / 语言 / 上学 / 进食 / 情绪 / 如厕 / 社交），断网出保守模板卡并标注来源
- 结构化调用：`__aiJSON()` 宽容解析（剥代码栏栅 / 截取大括号 / 容忍尾逗号）；数据仅存 localStorage

### 4.3 大模型在线集成（多服务商）

- 默认：免费体验接口（pollinations，无需 Key，联网即用）
- **在线演示通道（服务端代理，预留）**：Cloudflare Worker 代理 + `vercel-api-ai.js` 两套服务端实现已写好并文档化（`others/serverless/`），Key 只存服务端环境变量、前端零泄露；`REMOTE_PROXY` 常量当前**留空未启用**——实测 `workers.dev` 域名在国内被 DNS 污染与 SNI 阻断，待绑定自有域名后填入地址即可启用，届时评审打开即用、无需配置。当前评审体验请用「免费体验接口」或自填 Key
- 可选：DeepSeek（`deepseek-chat`）/ 智谱 GLM（`glm-4-flash`，看图 `glm-4v-flash`，浏览器直连受跨域限制，需代理）/ 通义千问（`qwen-turbo`，看图 `qwen3-vl-plus`）/ 自定义 OpenAI 兼容接口
- System Prompt 要求：先共情再展开、不机械分点、针对具体事情回答、不预设用户身份年龄、信息不够时反问细节、结尾引导继续说
- SSE 流式请求（`stream: true`）逐字渲染，超时 60s，max_tokens 1500
- **API Key 一律由用户在设置面板中填写、仅存于浏览器 localStorage，源码与仓库中不出现任何真实 Key**

### 4.4 四级链路降级

```
服务端代理（预留·绑定域名后启用） → 用户自配 Key 直连 → 免费体验接口（当前线上默认） → 本地知识库
        ↓ 任一层失败
界面明示具体原因（请求超时 / 跨域被拦 / Key 无效 / 频率或额度超限 / 服务端异常）→ 切到下一层
```

### 4.5 流式输出

- SSE（Server-Sent Events）逐 token 解析，增量渲染到对话气泡
- RAG 检索结果先在思考态展示（"已检索到 N 条站内科普资料"）
- 错误时友好降级提示，不白屏

### 4.6 Function Calling 工具调用

```
用户输入 → 大模型（tools 协议，含 3 个工具定义）
  ├─ 返回 tool_calls → 前端执行工具（板块跳转/知识库检索/感官体验）→ 回填 tool 结果 → 二次请求生成最终回复
  └─ 直接返回内容 → 流式渲染
免费接口（不支持 tools 协议）→ 本地关键词意图识别降级，同样给出板块入口按钮
```

### 4.7 RAG 向量检索

- 站内科普条目做字符二元组（bigram）TF 向量化，查询向量与条目向量算余弦相似度
- 与计分制关键词匹配混合排序（kw + sim×4），Top3 注入 System Prompt
- 纯前端实现、零依赖、离线可用；检索命中数在界面上可视化
