一、项目详情及使用方式

1.1 项目背景

自闭症（自闭症谱系障碍）是一种神经发育差异，国内患者数量超千万。社会大众对自闭症存在大量误解：以为是性格内向、是家庭教育不当、是"天才病"。同时，自闭症儿童家长、特教老师、医护人员等长期处于高压状态，缺乏情绪出口。

本项目以"理解、包容、希望"为基调，构建一个公益科普 Web 应用，面向普通市民、学生、志愿者、企业、自闭症儿童家长等多类人群，通过科普知识、真实故事、数据可视化、感官体验和 AI 心理陪伴，消除社会对自闭症的误解。

1.2 使用方式

本项目为单文件 HTML 应用，无需安装、无需构建：

1. 双击打开 `星夜入眠.html`

2. 浏览器自动加载，即可浏览全部内容

3. 点击导航栏切换板块：首页、科普、故事、数据、体验、对话、家庭、公益、关于

4. 点击"星语对话"进入 AI 心理陪伴，输入文字即可获得共情回答

5. 点击"进入星星的视角"观看自闭症儿童视角的公益视频

6. 支持 PC 端和手机端自适应浏览

二、项目亮点

2.1 双链路 AI 心理陪伴（核心亮点）

  • **在线模式**：接入 DeepSeek Chat API，支持流式输出、打字机效果
  • **本地兜底**：内置 120+ 条共情回答，覆盖 12 类人群 60+ 细分场景，比赛现场断网也能演示
  • **17 个科普话题专门回答**：自闭症、ADHD、抑郁、焦虑、失眠、压力等话题精确匹配长回答，问什么答什么
  • **计分制匹配**：统计用户输入命中几个关键词，选最贴合的条目，避免单关键词误判
  • **共情式回答**：每条回答先共情再展开，结尾引导用户继续说，不公式化、不预设身份年龄
  • **对话稳定**：全程不自动跳转站内板块，页面稳定

    • 2.2 感官体验模拟

    嵌入 B 站公益视频，让普通人直观感受自闭症儿童眼中的世界，用体验替代说教。视频带封面、点击暂停/继续，离开页面自动停止，下方黄色超链接可跳转 B 站原视频观看。

    2.3 数据可视化

    三张 Canvas 自绘图表（折线图 + 两个饼图），零依赖、离线可用，全部支持 hover 双向联动高亮，折线图 2016 年双数据分色标注，直观展示国内自闭症患病率趋势、国际对比、年龄分布。

    2.4 星空治愈视觉

    二次元星空动画背景 + 温暖配色，把沉重话题做温暖，不卖惨、不渲染悲情。

    2.5 隐私保护

    所有故事用插画代替真人照片，不使用患儿真实人脸。

    2.6 演示稳定性

    针对比赛现场环境做了大量稳定化处理：全站视频不自动播放、离开页面即暂停；背景音乐一键总开关；移除不可靠的 TTS 朗读；心理量表大字体显示。

    三、Web 网页使用情况概述

    3.1 板块结构

    | 板块 | 功能 |

    | 认识自闭症 | 科普翻页动画、常见误区、如何相处、科普公益视频 |

    | 看见他们 | 孩子视角、家长故事、老师视角、成长案例 |

    3.2 响应式

  • PC 端：多栏布局，完整展示
  • 手机端：自适应单栏，支持手势缩放

    • 四、关键技术

    4.1 前端技术

  • **原生 HTML5 + CSS3 + JavaScript（ES6+）**：单文件交付，无框架依赖
  • **原生 Canvas 2D 图表**：数据可视化，折线图 + 饼图，支持 hover 交互，零依赖
  • **响应式设计**：CSS 媒体查询 + 自适应布局
  • **视频内嵌**：MP4 base64 编码，离线可播放

    • 4.2 AI 技术

  • **大模型集成**：DeepSeek Chat API（OpenAI 兼容格式）
  • **RAG 本地知识库**：120+ 条人工撰写的共情回答，计分制关键词匹配
  • **17 话题精确回答**：科普站固定话题精确匹配长回答
  • **流式输出**：打字机效果逐字渲染
  • **四层降级**：在线 API → 17 话题 → 本地知识库 → 通用兜底
  • **System Prompt 工程**：先共情再展开、不机械分点、不预设身份、结尾引导

    • 4.3 交互技术

  • **打字机效果**：AI 回答逐字显示
  • **思考态**："星语正在思考..."状态提示
  • **图表联动**：hover 图形和图例双向高亮
  • **视频控制**：点击暂停/继续，离开页面自动暂停并回到开头
  • **音乐总开关**：一键关闭背景音乐
